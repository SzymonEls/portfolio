Personal project manager (2026)

A Flask web app, installable as a PWA. Each project is one living document: every heading in the plan becomes a step on the timeline, so it is easy to go from plan to action. It also tracks time per project and turns it into statistics. It runs in Docker on my own server; the demo below is a read-only copy. I have been using it every day for nearly three months.

Minecraft Server Auth plugin (2024)

Built with a team for our school's Minecraft server, which had several dozen players. The plugin authenticated players with a login and password; registration sent a verification code by e-mail and accepted only approved domains, so only people from the school could get in. The hard parts were security - a flaw in the login flow means anyone can take over an account - and handling many players logging in at once.

Auto deploy system (2026)

A Python service that watches selected GitHub branches and redeploys my projects whenever a new commit lands. It runs each project's own deploy script and reads its exit code, so a failed build is marked as broken instead of being retried every few minutes. It has no HTTP API and no open port - only its own clock can start a deployment. It currently keeps a few projects up to date on my server.

Python Docker CI/CD pytest In production
More on GitHub

Metal Planner - public transport search (2026)

A Flask web app that searches tram and bus connections in Wrocław, installable as a PWA. Instead of one computed route it draws every sensible way to get there at once - main corridors bright, niche detours barely visible - with a list of ready proposals beside the map: times, lines and transfers. Timetables come from the city's open GTFS feed; the server rebuilds its SQLite database every night and swaps it atomically. Built in a team.
